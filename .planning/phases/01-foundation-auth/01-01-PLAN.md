<decisions_made_in_this_plan>
Two things `01-CONTEXT.md` left open (and `01-RESEARCH.md` § Open Questions flagged) are decided here — do not re-litigate them:

1. **Android package name / bundle identifier: `com.goride.rider`.** Chosen to match the sibling driver app's `com.goride.driver` naming convention. This exact string must be used in Google Cloud Console's API-key restriction (plan 01-08).
2. **Maps key mechanism: `app.config.js` + `dotenv`, NOT hardcoding into `app.json`.** Rationale from `01-RESEARCH.md` Pitfall 4: static JSON never evaluates `process.env.X`, so a `app.json` containing the literal text `"process.env.GOOGLE_MAPS_API_KEY"` would be written verbatim into `AndroidManifest.xml`. A JS config file is genuinely executed, so `process.env` resolves. This also keeps the key out of committed source, consistent with the existing `.env` / `.env.example` convention inherited from the driver app.

Consequence: **no `app.json` file is created in this repo at all.** Only `app.config.js`.
</decisions_made_in_this_plan>
